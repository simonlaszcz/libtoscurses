This is an update of Eric Smith's port of Curses - primarily to
facilitate an Atari TOS port of Frotz. Several functions and support
for colour and other attributes have been added. This brings it closer
to ncurses but it still lacks a lot of functionality.

For MiNT note that a full ncurses distribution is available.
You should use that instead of this for MiNT.

Eric Smith's original code is on the __main__ branch.
